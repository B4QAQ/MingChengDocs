## 连接快应用

打开 SimpleFetch 插件，进入**连接页**：

1. 顶部「当前设备」卡片会显示已连接的手表（设备名 + 蓝牙地址），点击刷新按钮可重新扫描；
2. 下方「设备应用列表」会列出设备上已安装的快应用；
3. 找到需要联网的快应用，点击右侧的 `[连接]` 按钮；
4. 等待握手完成，状态圆点变绿即表示桥接已建立。

你也可以在快应用内通过「偏好设置 → 连接桥接网络」**由快应用主动发起握手**，效果相同。
<Callout type="warn">
如果想要由快应用主动发起连接,需要：  
1.亮屏/插件在前台
2.此次AstroBox插件启动时已经由插件发起握手连接过一次
</Callout>
### 应用状态说明

应用列表中的状态圆点实时反映连接情况：

| 圆点颜色 | 状态 | 说明 |
|----------|------|------|
| ⚪ 灰色 | 未连接 | 显示 `[连接]` 按钮 |
| 🟡 黄色 | 握手中 | 正在建立连接，显示禁用的 `[连接中…]` |
| 🟢 绿色 | 已连接 | 显示 `[断开]`，可展开查看请求统计 |
| 🔴 红色 | 连接失败 | 显示 `[重试]` 与失败原因 |

连接成功后，绿色圆点会展开请求统计（请求数 / 成功 / 失败）与最近状态。

## 使用桥接网络

连接成功后，快应用会自动将 `global.NetworkStatus` 置为 `'bridge'`，之后该快应用所有的 `fetch` 请求都会通过 SimpleFetch 走手机网络，**无需在快应用侧做任何额外配置**。

<Callout>
- 心跳由快应用每 10 秒发送一次，插件自动回复，桥接会保持连接；
- 若手机网络不可用或你手动断开，插件会通知快应用回退到本地网络状态；
- 通道本身断开时，快应用也会自动停用桥接。
</Callout>
<Callout type="warn">
请保证插件一直在前台,以保证所有请求都能被转发
</Callout>
