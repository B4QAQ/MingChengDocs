# 简介

MingChengAPI 是一个高自由度、开放的第三方快应用 API 服务，为开发者提供设备验证、天气数据、邮件服务、公告系统等功能。  
其具有可拓展性强，开发者友好，稳定安全等特点

## API基础信息

| 项目 | 值 |
|------|-----|
| 基础路径 | `https://api.b4qaq.cn/api/v2` |
| 认证方式 | APIKey或账密 |
| 统一响应格式 | `{ status: 200, result: ..., message: "..." }` |
<Callout type="info">
message可选
</Callout>
## 权限等级

```
Verify(设备验证) < User(普通用户) < Dev(开发者) < ROOT(超级管理员)
```
<Callout type="warn">
Service模块功能仅Verify权限可用
</Callout>
<Callout type="warn">
内部管理员API并不在本文档范围内
</Callout>
