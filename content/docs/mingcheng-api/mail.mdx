## 邮箱概览

| 项目 | 内容 |
|------|------|
| **API** | `POST /api/v2/mail/overview/:appname` |
| **说明** | 获取邮箱文件夹列表及未读数 |

**参数：**

| 参数 | 位置 | 必填 | 说明 |
|------|------|------|------|
| `appname` | path | 是 | 应用名 |
| `Key` | body | 是 | 设备 API Key |
| `email` | body | 是 | 邮箱地址 |
| `imapPass` | body | 是 | IMAP 密码/授权码 |
| `imapHost` | body | 是 | IMAP 服务器地址 |
| `imapPort` | body | 否 | IMAP 端口 |

## 验证邮箱配置

| 项目 | 内容 |
|------|------|
| **API** | `POST /api/v2/mail/verify/:appname` |
| **说明** | 验证邮箱 IMAP/SMTP 配置是否正确 |

**参数：**

| 参数 | 位置 | 必填 | 说明 |
|------|------|------|------|
| `Key` | body | 是 | 设备 API Key |
| `email` | body | 是 | 邮箱地址 |
| `imapPass` | body | 否 | IMAP 密码 |
| `imapHost` | body | 否 | IMAP 服务器 |
| `smtpPass` | body | 否 | SMTP 密码 |
| `smtpHost` | body | 否 | SMTP 服务器 |

**返回：**

```json
{
  "status": 200,
  "result": {
    "imap": { "success": true, "message": "连接成功" },
    "smtp": { "success": true, "message": "连接成功" }
  }
}
```
